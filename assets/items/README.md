# REDLINE AGENT — アイテム絵のファイル契約（v1.7）

装備画面は、各アイテムについて次のファイルを探しに行きます。
ファイルが無い間は、装備画面では「名前プレート」（文字だけの仮表示）になります。
絵が用意できたら、このフォルダに下記の名前で置くだけで自動的に差し替わります。

指示文: `~/workspace/goals/new-smartphone-app-concepts/files/redline-agent-items-art-brief-2026-11-23.md`

## ゲーム中用（お供のみ、v1.7 で組み込み済み）

お供を装備すると、ゲーム中にビルボードとしてプレイヤーに同行します。
ファイルが無い場合は表示だけが黙ってスキップされ、効果はそのまま働きます。
表示サイズはテクスチャ自身のアスペクト比から決まります。

| ファイル名 | アイテム | 実測サイズ（アスペクト比） | ゲーム中の配置 |
|---|---|---|---|
| `dog-game.png` | 犬 | 350×650（0.538）納品済み | 地面、プレイヤーの横（x +0.9m）、高さ ≈0.75m |
| `hawk-game.png` | 鷹 | 1127×462（2.439）納品済み | 上空・やや前方を旋回（半径 ≈1.2m、高さ ≈2.6m）、幅 ≈2.0m |
| `atkdrone-game.png` | 攻撃ドローン | 未納品 | 肩の高さでホバリング（x −0.9m、y ≈1.6m） |
| `shdrone-game.png` | シールドドローン | 768×679（1.131）納品済み | 肩の高さでホバリング（x −0.9m、y ≈1.6m） |

武器・防具のゲーム中絵は作りません（装備しても主人公の見た目は変わらず、性能のみ反映 — 確定仕様）。
